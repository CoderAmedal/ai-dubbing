# 执行计划 0008：启动台首页（Launcher）一比一模仿

> 创建：2026-08-04
> 完成：2026-08-04
> 前置：0001-0007（全链路 + 桌面壳 + Provider 抽象 + 打包）
> 目标：按 `docs/design-docs/design-pic/index.png` **一比一模仿**实现"启动台"首页——侧栏导航、顶栏搜索、开始创作卡片、最近任务、环境就绪度、工具箱、快速上手。把现有单页表单 UI 升级为产品级工作台壳。

## 背景

设计图（design-pic/index.png）是目标产品形态：深色桌面工作台，首页即"启动台"——用户打开应用第一眼看到任务入口卡片 + 环境状态 + 最近任务。当前 UI（0005/0007）是纵向表单页，功能完备但无产品形态。本阶段只做**界面与信息架构**，不改 pipeline 逻辑。

## 设计图功能点拆解（必须逐项覆盖）

| 区域 | 功能点 | 实现方式 |
|------|--------|---------|
| 左侧栏 | Logo + 9 个导航项（启动台/下载/字幕/校对/配音/引擎/翻译/词库/音色）+ 底部设置 + 引擎/GPU 状态条 | 壳布局；启动台/引擎/词库为真实页面，其余占位页（"规划中"） |
| 顶栏 | 页面标题、居中搜索框（Ctrl+K 唤起）、右侧模式指示（自动·待首次转写）、状态图标 | 壳布局；Ctrl+K 聚焦搜索，搜索过滤导航与工具 |
| 问候区 | "晚上好"（按时段）+ 日期星期 + 提示文案 | JS 动态生成 |

| 工具箱 | 4 项（视频下载/校对字幕/合成到视频/配音） | 入口卡片，跳对应页面（占位页可接受） |

| 右下角 | 版本号 | `/api/health` 返回版本 |

## 目标与范围

**范围内**：
- 三栏壳布局（侧栏/主区/右面板）+ 顶栏，深色主题按设计图取色
- 启动台首页全部功能点（上表）
- 后端：`GET /api/tasks`（任务列表）、`GET /api/env/status`（环境探测）
- 现有功能迁移为子页面：引擎（provider+模型+API Key）、词库、任务运行页（从卡片进入）
- 快捷键：Ctrl+K 聚焦搜索、Ctrl+, 打开设置
- 拖拽：Tauri 环境监听 `tauri://drag-drop` 取真实路径；浏览器环境提示手动输入

**范围外**：
- 下载/字幕/校对/翻译/音色等页面的真实功能（仅导航占位，后续阶段）
- 字幕烧录、SRT 翻译向导的真实实现
- pipeline 逻辑改动
