# 执行计划 0001：MVP 端到端链路验证

> 状态：✅ 已完成 — 2026-08-04
> 创建：2026-08-04
> 目标：在 CPU 机器上跑通"视频 → 识别 → 翻译 → 配音 → 混音"最小闭环，验证技术可行性。

## 背景

产品核心链路包含 7 个 AI/处理环节。在写正式产品代码前，先用最小脚本验证每个环节可工作、可串联。本机：AMD Ryzen 7 6800H（16核）/ 14GB 内存 / CPU 模式（无 NVIDIA GPU）。

## 步骤完成情况

| # | 任务 | 状态 | 说明 |
|---|------|------|------|
| 1 | 搭建 Python venv（uv）+ 安装 faster-whisper | ✅ | `uv venv .venv` + `uv pip install -e ".[dev]"`，含 faster-whisper / edge-tts / openai |
| 2 | 下载 faster-whisper-small | ✅ | 实际走 huggingface.co（hf-mirror 会 308 重定向回官方域名，新版 huggingface_hub 校验失败） |

| 4 | 翻译验证：DeepSeek API | ✅ | `scripts/step2_translate.py`，英文→中文自然（示例：→"大家好，欢迎来到AI配音工作室。"） |

## 决策日志

- **2026-08-04**：TTS 先用 edge-tts 验证链路（零成本、无需模型），音色克隆（GPT-SoVITS）作为独立里程碑——因为 CPU 上训练音色模型耗时长，先证明链路通，再换真实音色。
- **2026-08-04**：模型下载原本计划走 hf-mirror 直连，实测 hf-mirror.com 对 resolve 路径返回 308 重定向到 huggingface.co，且新版 huggingface_hub 校验 X-Repo-Commit 头导致失败。**改为 huggingface.co 直连**（经本机代理）。
- **2026-08-04**：本机代理 `all_proxy=socks://127.0.0.1:7897` 前缀 httpx 不识别（只认 `socks5://`），且 ALL_PROXY 优先级高于 http/https 代理 → 运行联网脚本前需 `unset all_proxy ALL_PROXY`。
- **2026-08-04**：翻译环节用户选定 DeepSeek API（提供 DEEPSEEK_API_KEY），本地 Qwen 翻译作为后续里程碑。
- **2026-08-04**：测试素材由 edge-tts 生成英文语音 + ffmpeg 生成 1280x720 背景画面合成 `assets/demo.mp4`（8s），无需外部下载。

## 风险与验证结果

- CPU 上 whisper large 太慢 → **small 模型实测 8s 音频识别 <2s**，链路验证充分，生产换 GPU
- ffmpeg 未安装 → **imageio-ffmpeg 内置静态 ffmpeg 7.0.2**，无需 apt
- 中文硬字幕渲染 → **系统有 Noto Serif CJK**，force_style 需整体用单引号包裹（否则逗号被 filtergraph 当过滤器分隔符）

## 验收结果
