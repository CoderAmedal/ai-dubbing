## 产品定位（一句话）

**本地 AI 视频翻译配音桌面应用**：上传外语视频，自动识别说话人、翻译，并用**原说话人音色**重新配音，输出中文成片。对标海风声影 Studio。

## 核心功能矩阵

| 功能 | 说明 | 优先级 |
|------|------|--------|
| 多说话人识别 | 自动区分视频里每个人 | P0 |
| 音色克隆 | 为每个说话人克隆专属音色 | P0 |
| AI 翻译 | 中/英/日/韩等 20+ 语言 | P0 |
| 音色配音 | 用克隆音色朗读译文 | P0 |
| 字幕生成 | 双语字幕 SRT/ASS | P1 |
| 弹性时间轴 | 中文语速自然优先 | P1 |
| 长停顿剪辑 | 自动裁剪冗长静音 | P1 |
| 批量处理 | 多视频排队 | P1 |
