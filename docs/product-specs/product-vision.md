# 产品愿景

> 状态：✅ 已确认 — 2026-08-04

## 一句话愿景

让每个创作者都能**用自己的声音说任何语言**——上传外语视频，一键产出"听起来像本人说中文"的成片。

## 目标用户

1. 自媒体博主（YouTube/TikTok 出海，视频多语种化）
2. 影视/课程本地化团队
3. 跨国企业培训视频
4. 个人学习（外语视频转中文）

## 核心价值主张

| 痛点 | 我们的解法 |
|------|-----------|
| 机器翻译腔、音色生硬 | **克隆原说话人音色**配音 |
| 云端工具贵、素材要上传 | **全本地处理**，零 API 成本，素材不出本机 |
| 开源工具配置复杂 | **解压即用**，自动检测硬件 |
| 配音忽快忽慢 | **弹性时间轴**，中文语速自然优先 |
| 多角色视频难处理 | **自动说话人分离**，各角色各音色 |

## 非目标（明确不做）

- 不做云端 SaaS（初期），聚焦本地软件
- 不做实时流式翻译（Phase 3 再说）
- 不做影视级口型精修（Phase 3 可选）

## 成功指标

- MVP：单视频端到端处理 < 15 分钟（CPU），中文配音自然度主观评分 ≥ 4/5
- 产品化：用户从导入到成片 ≤ 5 步操作
- 商业：永久会员定价对标海风声影（368 元）
