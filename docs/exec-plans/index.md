## 工作流

1. 复杂任务 → 在 `active/` 创建计划（`NNNN-名称.md`）
2. 计划含：目标、步骤、验收标准、决策日志、进度
3. 完成 → 移到 `completed/`，更新本索引
4. 发现债务 → 记入 tech-debt-tracker.md
