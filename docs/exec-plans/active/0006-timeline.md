# 执行计划 0006：弹性时间轴 + 长停顿剪辑

> 状态：⏳ 排队中（0005 完成后启动）
> 创建：2026-08-04
> 前置：0001-0004（pipeline 完整）、0005（桌面壳）
> 目标：实现海风声影的核心卖点——**中文配音优先自然语速**，通过弹性时间轴对齐（不强行压缩/拉伸），并自动检测与裁剪成片中的长停顿/静音。

## 背景

当前混音（step4_mux）用 adelay + amix 把译文语音按原时间轴硬对齐。中文比英文短/长时会导致：语速过快/过慢、忽快忽慢、或出现突兀的长停顿。海风声影主打"弹性时间轴 + 长停顿一键剪辑"。

## 目标与范围

**范围内**：
- 译文语音时长与原分段时长差异处理（变速 ±15% 内，rubberband 高质量变速）
- 短译文 → 保留自然节奏（允许该段略短，字幕窗口微调）
- 长停顿检测（>1.5s 静音）→ 自动裁剪 + 交叉淡化过渡
- step4_mux 升级 + run_e2e 集成开关

**范围外**：
- 画面级剪辑（裁掉画面帧）——先做音频时间轴
- 口型同步

## 步骤（草拟，启动时细化）

1. 测量：真实成片中译文 vs 原时长分布
2. 变速方案选型（rubberband / ffmpeg atempo）
3. 弹性对齐算法实现
4. 长停顿检测与裁剪
5. 集成 step4 + run_e2e 开关（`--elastic-timeline`）
6. 主观听感验证（对照硬对齐版本）

## 验收（草拟）

- 成片中文语速自然度主观评分 ≥ 硬对齐版本
- 无 >1.5s 突兀停顿（裁剪后）
- 变速幅度 ≤ ±15%（无忽快忽慢）
- 单人/多角色/真实长视频回归不破
